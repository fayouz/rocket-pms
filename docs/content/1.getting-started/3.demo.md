La démo contient deux logements fictifs (« Le port » et « Les vignes »), leurs réservations autour d'aujourd'hui, une conversation et une serrure par logement. Aucune clé Lodgify ni jeton Nuki : rien n'est envoyé, ni message ni code.

## Scénario conseillé

1. **Logements → Le port** : la réservation en cours est sélectionnée, avec sa conversation et la valeur du séjour.
2. Filtre **À venir** : la réservation d'Anna Kowalska et son code clavier prévu.
3. Onglet **Serrures** : état et batterie de la serrure, code d'Anna, historique.
4. **Timeline** : arrivées, départs, codes et passages de tous les logements.
