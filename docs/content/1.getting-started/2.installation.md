## Docker Compose

```bash
docker compose up -d --build
```

- Application : http://localhost:3700 (la configuration initiale crée le compte administrateur)
- API et documentation OpenAPI : http://localhost:8700/api/docs

## Développement sans Docker

```bash
# backend (PHP 8.4, PostgreSQL)
cd backend && composer install
php bin/console lexik:jwt:generate-keypair
php bin/console doctrine:migrations:migrate
php bin/console app:demo:seed            # avec DEMO_MODE=1 : logements de démo
php -S 127.0.0.1:8700 -t public

# frontend
cd frontend && npm install && npm run dev -- --port 3700
```

## Lodgify et Nuki

Renseigne `LODGIFY_API_KEY` (clé d'API du compte Lodgify) et `NUKI_API_TOKEN` (jeton de l'API web Nuki, avec le droit `smartlock.auth` pour créer les codes), redémarre, puis **Logements → Synchroniser Lodgify et Nuki** et associe chaque serrure à son logement (**Administration → Serrures Nuki**).
