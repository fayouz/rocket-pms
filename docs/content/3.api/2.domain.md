---
title: API du domaine
description: Logements, réservations, conversations, lieu Rocket Place et accès.
---

Toutes les routes demandent un utilisateur connecté (jeton JWT) ou une application externe (`Authorization: Bearer rpm_…` et `X-Impersonate-User`). Envoyer `Accept: application/json`.

| Méthode | Route | Rôle |
|---|---|---|
| GET | `/api/properties` | Logements |
| GET · PATCH | `/api/properties/{id}` | Un logement ; modification (nom, couleur) : administrateur |
| POST | `/api/properties/sync` | Crée les logements depuis Lodgify (administrateur) |
| GET | `/api/properties/{id}/bookings` | Réservations (60 derniers jours et à venir) avec leur code clavier |
| GET | `/api/properties/{id}/bookings/{bookingId}/pricing` | Valeur et détail du prix |
| GET · POST | `/api/properties/{id}/bookings/{bookingId}/conversation` | Conversation ; réponse `{"text", "messageId": "<uuid>"}` |
| GET | `/api/places` | Lieux de Rocket Place (administrateur) |
| PUT · POST | `/api/properties/{id}/place` | Lie le logement à un lieu `{"placeId": "<uuid>" \| null}` · crée un lieu depuis le logement (administrateur) |
| GET | `/api/properties/{id}/locks` · `/api/locks` | Serrures du lieu · toutes (administrateur) |
| PUT | `/api/locks/{nukiId}` | Lieu ouvert par la serrure `{"place": "<uuid>" \| null}` (administrateur) |
| GET | `/api/properties/{id}/codes` · `/access-grants` | Codes des séjours à venir · accès du lieu (prévus au passage, `externalRef` = réservation) |
| POST | `/api/properties/{id}/access-grants/{grantId}/send` | Envoie le code à la serrure (action réelle, sur clic) · `/revoke` (administrateur) |
| GET | `/api/properties/{id}/domotique` · `/documents[…]` · `/stock` | Relais vers le lieu Rocket Place ; `PATCH /stock/{levelId}` `{"level": "ok"\|"low"\|"empty"}` |

Sans lieu lié, les routes relayées répondent **409**.
| GET | `/api/properties/{id}/timeline` · `/api/timeline` | Timeline (`?past=` jours, défaut 3 ; `?future=`, défaut 45) |
