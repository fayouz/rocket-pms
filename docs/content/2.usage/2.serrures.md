---
title: Serrures et codes
description: Serrures Nuki, codes clavier par séjour.
---

Un administrateur associe chaque serrure Nuki à un logement (**Administration → Serrures Nuki**, après « Synchroniser » sur la page Logements).

Pour chaque séjour **à venir** d'un logement équipé, un **code clavier** est prévu automatiquement : 6 chiffres, ouvert **1 h avant l'arrivée** et fermé **1 h après le départ** (horaires Lodgify, fuseau `PMS_TIMEZONE`).

Le code n'est **envoyé à la serrure que sur ton clic** (« Créer sur Nuki » ou « Générer sur la serrure »), après confirmation. Un séjour commencé n'est jamais modifié. Si les dates d'une réservation changent après l'envoi, le code est signalé « à refaire à la main dans Nuki ».

Le jeton Nuki doit avoir le droit `smartlock.auth` pour créer des codes.
