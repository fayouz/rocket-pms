---
title: Domotique
description: Connecteurs (plugins) par logement, onglet Domotique.
---

Un **plugin** décrit un type de service (Homey, service web…) : ses champs de configuration et ce qu'il sait afficher. Le catalogue est intégré au code (**Administration → Plugins**), aucun code externe n'est exécuté.

Un **connecteur** est un plugin configuré pour un logement. Un logement peut en avoir plusieurs, y compris du même plugin (par exemple deux Homey). Un administrateur les gère dans l'onglet **Domotique** du logement : ajout, modification, activation, suppression, test.

- **Homey** : appareils du logement et leurs valeurs (températures, prises, capteurs…), en lecture seule. Sans adresse locale configurée : appareils de démonstration.
- **Service web** : n'importe quelle API HTTP/JSON en lecture seule (une adresse de base + un chemin qui répond en JSON).

Les secrets (clé d'API, jeton…) ne sont **jamais stockés en base** : un champ secret ne contient que le **nom** d'une variable de `.env`, obligatoirement préfixée `CONNECTOR_`, pour qu'un connecteur ne puisse jamais lire un autre secret de l'application.
